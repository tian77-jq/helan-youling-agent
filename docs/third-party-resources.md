# 第三方资源与非团队成果说明

| 资源 | 用途 | 状态 | 说明 |
| --- | --- | --- | --- |

## AI / 模型服务

当前代码未写入任何第三方模型厂商 API Key。CloudBase AI 的模型提供方和模型 ID 由 `config/cloud.js` 读取，是否启用由 CloudBase 控制台决定；Vision Provider 仍未配置。正式启用后必须补充：服务商、模型名称、版本、用途、许可/计费方式、数据处理政策和团队二次开发范围。

## 图片、图标与字体

- 小程序图标目前使用 Unicode emoji 与文字符号，不含额外图标库。
- 字体使用系统字体 `Arial`、`PingFang SC`、`STSong` / `Songti SC` 回退，不分发字体文件。
- `assets/images` 中包含团队现有的萌宠、产品、景区联名和宁夏美食联名视觉。提交比赛前，团队必须逐张确认著作权、肖像权、商标/景区名称使用授权及 AI 生成素材说明，并将授权文件纳入提交材料。

## 开源依赖

项目当前没有 `package.json`，未发现随包分发的第三方开源库。

## 地图与实时数据

当前未接入地图 SDK、天气、票务、酒店、餐厅营业时间或实时交通服务。产品明确提示用户以官方最新公告为准。以后接入时需在本文档补充服务来源与授权。
