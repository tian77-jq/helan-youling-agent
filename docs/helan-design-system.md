# 贺兰有灵 Design System（V1）

## Tokens

- `primary`: 贺兰山岩灰与深青绿，用于主导航与主要操作；
- `gold`: 黄河鎏金，用于强调和结果状态；
- `sand`: 荒漠暖沙，用于页面背景和信息卡；
- `ink`: 墨色正文；`surface`: 暖白卡面；`night`: 夜游深靛。
- 圆角：卡片 24–28rpx，Chip 999rpx；间距基准 8rpx；
- 动效：点击 80–150ms，页面进入 200–350ms，常规过渡 180–280ms。

## Components

统一使用 Page Hero、Section Title、Primary Card、Tag、Action、Bottom Sheet、Loading、Empty、Error。Trip 使用时间线，QA 使用结论优先的 Answer Card，AI 灵境使用生成状态与“AI生成/合成内容”标识。

## Mascot rules

岩羊负责生态，骆驼负责西夏/丝路/黄河历史，沙狐负责旅行、美食、夜游与路线。人格可以改变表达，不能改变事实。字幕模式必须明确展示，不伪装成音频。
