# Ningxia Contextual Design System

基础 Token 统一使用 `styles/variables.wxss` 与 `styles/theme.wxss`。页面差异通过场景上下文表达：

- 首页 / 贺兰山：墨绿、岩灰、晨光金，山脊线和安静呼吸。
- 发现 / 黄河湖城：河蓝、湖绿、暖金，水纹与横向景观卡。
- 文创 / 沙漠文明：沙金、岩赭、宣纸白，沙丘弧线与文化印记。
- 我的 / 星空记忆：深蓝、星空紫、微金，星点与继续旅程。

共用规则：圆角 24–32rpx、卡片间距 18–24rpx、正文行高 1.6–1.7；按钮保持高对比和原生可点击面积，不以装饰替代信息层级。
