# 腾讯混元与贺兰有灵的技术创新

混元提供通用语言与图像生成能力，贺兰有灵提供宁夏文旅知识、Evidence、三萌宠 IP、Prompt 约束和商业场景。创新不在于裸接模型，而在于把通用模型约束进地方文化资产与游客共创流程。

## 链路

用户 → Agent 控制层 → 宁夏知识检索 → 混元文字/生图 Provider → 可信结果/数字资产 → 分享与文创。

## 模式

- `LOCAL_DEMO_MODE`：比赛稳定模式。
- `HUNYUAN_MODE`：云函数生产模式，前端只通过 service/provider 调用。

任何 API 超时、余额不足或网络失败，都返回降级结果，不影响首页和基础路线。
