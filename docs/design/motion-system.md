# Ningxia Motion Grammar

动感由地域动作表达，而不是粒子、背景视频或大动画：

- MOUNTAIN：RISE / BREATHE / REVEAL；首页远山慢视差，中层内容上升进入。
- RIVER：FLOW / CONNECT / GUIDE；发现页用抽象路径串联选择与内容。
- DESERT：REVEAL / DRIFT / LAYER；文创与卡片用沙丘层揭示内容。
- STAR：GLOW / REMEMBER / RETURN；记忆保存只触发一次短暂微光。
- SHAPOTOU：FLOW → REVEAL → GLOW，对应黄河、沙海、日落与星空。

默认 AMBIENT，最多三个低频动画；系统 reduced-motion 时关闭非必要动画。禁止 Lottie、WebGL、Particle Engine、背景视频与 GIF 大动画。
