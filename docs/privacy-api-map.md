# 贺兰有灵 · 隐私 API 映射（RC）

构建：`20260829-gold-production-rc1`；审计时间：2026-08-29。本表基于代码扫描，不替代微信公众平台最终检测与审核结论。

| 功能 | 实际接口 / 文件 | 处理的数据或权限 | 触发条件 | 隐私指引填写建议 |
| --- | --- | --- | --- | --- |
| 拍照识景 | `wx.chooseMedia`，`feature/photo/index.js` | 用户选取的相册图片或拍摄图片 | 用户主动点击选择/拍照 | 按平台字段声明相册/相机图片用于识别景物 |
| 保存 AI 作品 | `wx.cloud.downloadFile`、`wx.saveImageToPhotosAlbum`，`feature/create/result.js` | 向用户设备相册写入图片 | 用户主动点击“保存作品” | 按平台字段声明保存到相册；拒绝不影响查看作品 |
| 复制文案 | `wx.setClipboardData`，`feature/memory/index.js` | 用户主动复制的卡片文案 | 用户主动点击复制 | 按公众平台检测结果填写剪贴板相关说明 |
| 云端 AI 文本 / 图片 / 语音 | `wx.cloud.callFunction`，各业务服务 | 用户主动提交的提问、创作选择或需要合成的文字 | 仅在用户发起相应功能时 | 说明 AI 服务用途与内容处理；当前语音发布模式为字幕，不申请录音权限 |
| 云存储读取 | `wx.cloud.downloadFile`，作品保存与语音服务 | 云端生成资源的临时下载 | 用户查看或保存已生成资源 | 在隐私指引的存储/服务说明中如实说明 |

未发现：定位、录音/麦克风、手机号、用户头像昵称/用户资料、直接 HTTP 请求、支付接口。

平台动作：微信要求涉及个人信息处理时，只有在隐私保护指引中声明对应信息后才能调用隐私接口；提交审核时应以本表和实际运行行为为准逐项核对并完成平台配置。[腾讯云对微信规则的说明](https://cloud.tencent.cn/document/product/1301/97930)
