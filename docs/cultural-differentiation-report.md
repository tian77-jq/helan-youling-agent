# 《贺兰有灵》文化差异化报告

## 核心判断

差异化不在“有 AI”或“有三只萌宠”，而在于把宁夏的山、文明、河、路、沙、人间烟火、夜和非遗组织成一个可进入、可理解、可行动、可再创作的故事系统。

## 三个不可替代的组合

1. **地域主线**：贺兰山—西夏—黄河—丝路—沙漠—城市生活形成纵向文化骨架。
2. **角色分工**：岩羊讲生态与时间，骆驼讲文明与连接，沙狐讲当代旅行与生活。
3. **行动闭环**：故事详情 → 地点/知识 → Trip 规划或现场任务 → AI Create 文化再表达。

## 与普通文旅 AI 的区别

普通问答的最小单元是“问题—答案”；本项目的最小单元是“问题—角色—地点—证据—互动—行动”。普通路线的最小单元是“景点列表”；本项目的路线从故事动机出发，并保留时间、同行人与安全约束。

## 当前可验收资产

- 8 条核心故事，统一 schema。
- 每条故事 5 个递进层级。
- 故事中心复用现有 IP Story 入口，不增加无必要的页面数量。
- 角色、地点、知识 ID、Trip 和 AI Create 已有代码连接点。
- `scripts/cultural-storytelling-regression.js` 提供 60+ 项本地静态回归。

## 仍需上线前验证的事项

景区实时开放信息、路线导航、真实音频、云端图片生成、真实用户访谈、非遗传承人/景区合作授权、线上性能与真机兼容性，不能用本地脚本结果替代。
