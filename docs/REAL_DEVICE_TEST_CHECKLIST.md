# REAL_DEVICE_TEST_CHECKLIST

## 黄金核心链

1. 打开首页，确认首页首屏、AI Hero、萌宠/景区/美食入口正常。
2. 进入「AI 灵游」，输入：`第一次来宁夏，两天时间，喜欢历史和美食。`
3. 生成路线，确认出现结构化行程、宁夏知识内容和来源提示。
4. 点击「少走一点」，确认路线连续调整成功。
5. 再次调整一次，确认不会丢失原有行程上下文。
6. 进入萌宠讲解入口，确认能显示本地 Knowledge 讲解和安全提示。
7. 切换 `English`，重复一次核心路线输出检查。
8. 切换 `العربية`，重复一次核心路线输出检查。
9. 进入「旅行纪念」，确认页面可打开、内容可保存/回看。
10. 使用微信分享，确认分享卡片可打开并回到带参数的 AI 灵游路线。
11. 依次打开 IP 详情、推荐结果、商城详情等分包页面，确认无 `page not found` 或分包加载错误。
