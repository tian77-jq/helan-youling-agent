# 贺兰灵物用户测试计划

## 目标

验证一等奖核心闭环，不制造参与人数或行为数据。测试记录只保存匿名结果和问题，不保存聊天正文、照片、身份证、精确位置或真实身份。

## 核心任务

1. 首页点击「让灵灵规划」，确认进入 AI 灵游。
2. 输入「第一次来宁夏，两天时间，喜欢历史和美食」，确认得到卡片化路线。
3. 点击「少走一点」，确认保留上下文并减少节奏压力。
4. 点击行程卡片，确认萌宠知识讲解有 Knowledge 来源。
5. 切换 English 与 العربية，确认核心输出可读。
6. 进入旅行纪念，生成、保存并分享。
7. Vision 未 Ready 时，确认入口显示安全内测反馈，不上传或编造识别结果。

## 记录字段

- 匿名测试编号
- 设备与微信版本
- 每项任务 PASS / FAIL
- 是否出现无响应、路由错误、图片裁切、事实幻觉
- 用户是否愿意分享
- 建议与复现步骤

## 成功标准

- 核心任务完成率 ≥90%
- 无死按钮、无 `page not found`、无 `undefined/null` 用户可见错误
- 票价、开放时间、天气、实时交通等未核验信息必须明确提示
- 不记录或上传敏感数据
