# AI 灵游：已去景点与行程约束修复

## 用户反馈对应问题

用户明确说“沙坡头、腾格里沙漠都去过”，旧路线仍可能把它们作为中卫默认景点。这是约束解析缺失，不应交给大模型自由发挥。

## 已修复

- 增加“去过、玩过、到过、逛过、已经去过”等中文表达识别。
- 增加沙坡头、腾格里沙漠、66 号公路、金沙岛、乌兰湖、天鹅湖等中卫目的地别名。
- `excludedStops` 作为硬约束，默认路线、换景点路线和补点逻辑均不得重新加入。
- 用户只是在描述已去的中卫目的地时，不再把中卫误当作本次住宿城市，改从银川的已核验本地景点规划候选。
- 增加情侣/对象人数识别；浪漫需求优先安排文化体验和傍晚览山公园，并保留晚餐、休息时段。
- 页面显示“已排除你去过的地点”，让推荐依据可核验。

## 验证样例

输入：`第三次来宁夏了，沙坡头和腾格里沙漠都去过了，想去点别的地方，晚上想浪漫一点，玩两天跟我对象`

结果：

- `excludedStops`: `shapotou`, `tengger-desert`
- 路线不再包含沙坡头、腾格里沙漠
- 人数识别为 2 人
- 规划为银川已核验景点，包含西夏陵、宁夏博物馆、镇北堡、贺兰山岩画与傍晚览山公园
- 所有景点和美食项均来自本地知识库；票价、开放时间、实时交通仍要求以官方公告核验
