# 隐私数据与权限映射（发布前核对）

| 功能 | 实际 API | 数据/权限 | 用途 | 云端上传 | 发布前后台动作 |
|---|---|---|---|---|---|
| 拍照识景 | `wx.chooseMedia` | 用户选择的图片或相机图片 | 由用户主动选择后用于识景 | 以运行时功能实现为准 | 在隐私保护指引中按实际实现声明图片/相机能力 |
| 保存 AI 作品 | `wx.downloadFile`、`wx.saveImageToPhotosAlbum` | 用户相册写入权限 | 仅在点击“保存作品”后保存 | 否（保存至本机相册） | 在隐私保护指引中声明；拒绝权限不影响生成结果 |
| 复制文案 | `wx.setClipboardData` | 剪贴板内容 | 用户主动复制文案 | 否 | 按微信后台隐私接口检测结果确认是否需声明 |
| TTS 讲解 | 无录音 API | 不申请麦克风 | 文本转音频播放 | Provider 依赖云端 | 不把 TTS 错误声明成录音权限需求 |

本表来自源码扫描，不替代微信后台最终的隐私接口检测或法律意见。
