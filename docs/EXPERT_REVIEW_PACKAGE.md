# 专家审核包

用途：提供给旅游管理教师、持证导游、文旅从业者审核。当前不声称已有专家审核。

## 审核字段

每条知识需记录：`id`、`title`、`source`、`reviewStatus`、`reviewedBy`、`reviewedAt`、`corrections`。

状态只能使用：`UNVERIFIED`、`SOURCE_VERIFIED`、`EXPERT_REVIEWED`。没有真实审核人和日期时不得使用 `EXPERT_REVIEWED`。

## 建议首批 20–30 条

西夏陵、贺兰山岩画、贺兰山生态、黄河文化、沙坡头、镇北堡、西部影视城、宁夏博物馆、阅海湖、怀远夜市、宁夏葡萄酒、枸杞、羊杂碎、八宝茶、手抓羊肉，以及相关生态与旅游文化条目。
