# 反向失败审计

以下 40 个风险是发布前 Anti-Failure Gate：

1. 首屏像普通学生作品；2. 3 秒看不懂产品；3. AI 像通用聊天框；4. 三 IP 只是贴图；5. 宁夏替换成别省仍成立；6. 故事是文字墙；7. 没有地点锚点；8. 路线是景点清单；9. 默认生成三天；10. 角色错配；11. 当前轮次丢失；12. 事实无证据；13. 推荐越过知识边界；14. 夜游无返程提示；15. 生态内容鼓励打扰；16. Story 无行动出口；17. Trip 无为什么停留；18. Create 无文化上下文；19. 文化印记伪装到访认证；20. 分享标题空泛；21. 入口死按钮；22. Coming Soon 暴露技术错误；23. 页面层级混乱；24. 按钮过多；25. 加载反馈不足；26. 包体失控；27. 版权素材不清；28. 虚构合作；29. 虚构订单；30. 虚构用户数据；31. 商业模式只有口号；32. 无真实需求证据；33. 无上线计划；34. 无隐私边界；35. 无人工核验；36. 只讲调用模型；37. 无失败回退；38. 无真机证据；39. Demo 依赖未完成语音；40. 评委只记住“用了混元”。

关键 Gate：`GENERIC_AI_RISK`、`LOCAL_IDENTITY_RISK`、`DEAD_FEATURE_RISK`、`EVIDENCE_RISK`、`CLAIM_COMPLIANCE_RISK`。
