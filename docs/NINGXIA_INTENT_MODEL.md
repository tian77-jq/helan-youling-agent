# 宁夏文旅意图识别增强

构建版本：`20260825-ningxia-intent-rich-21`

意图不再只有“历史 / 自然 / 美食”三类，而是识别宁夏真实体验：

| 信号 | 宁夏本地映射 |
|---|---|
| entertainment | 沙坡头沙漠与黄河互动项目、金沙岛、镇北堡体验场景 |
| road_trip | 66号公路、腾格里沙漠、乌兰湖自驾线路 |
| desert | 沙坡头、腾格里、金沙岛、乌兰湖 |
| water_wetland | 沙湖、天鹅湖、黄河大峡谷、金沙岛 |
| sunset_night | 览山公园、黄河古渡等傍晚体验 |
| history_culture | 西夏陵、贺兰山岩画、水洞沟、宁夏博物馆、镇北堡 |
| food_wine | 宁夏羊肉、八宝茶、地方小吃、贺兰山东麓葡萄酒 |
| nature_ecology | 贺兰山、盐湖、湿地、森林与丹霞 |
| photography | 览山、沙漠、湖泊、岩画等出片场景 |
| slow_city | 城市慢游、少点位、休息优先 |

规则：

1. 用户未表达的兴趣不写入画像，不再默认“历史文化 + 自然生态”。
2. 用户点名景区、体验或活动时作为硬约束传给混元和本地路线引擎。
3. 只有缺少关键条件时追问一个问题；追问会给出宁夏本地选项，而不是泛化选项。
4. 没有指定城市但明确体验类型时，优先体验对应的宁夏代表景点，不被默认银川起点覆盖。
5. 混元只负责理解和组织，景点实体、文化事实和安全限制仍由本地知识库校验。
