# 贺兰有灵 · Ningxia Visual DNA

视觉冻结原则：基础交互沿用微信原生能力，地域识别由色彩、山河轮廓、文化纹理、三只 IP 和页面情绪共同完成。新增装饰优先 CSS，避免大图片、大依赖和版权不明素材。

## 四个空间

| 空间 | 宁夏意象 | 职责 |
| --- | --- | --- |
| 首页 | 贺兰山晨光 | 第一次看见宁夏，进入 AI 灵游 |
| 发现 | 黄河 × 湖城 | 走进景区、故事、美食与城市生活 |
| 文创展厅 | 沙漠 × 西夏 × 非遗 | 把文化转成可带走的原创设计 |
| 我的 | 星空 × 记忆 | 继续旅行、故事、纪念卡与徽章 |

## Token

- 墨绿 `#174F50`：贺兰山、可信、主行动
- 河蓝 `#356F7A`：黄河、湖泊、发现
- 沙金 `#A56E38`：沙漠、暖光、文创
- 岩赭 `#8B5A2B`：岩画、西夏、文化强调
- 星空紫 `#6B6288`：记忆、夜晚、回访
- 宣纸 `#FFF8EE`：宁夏日光下的留白

## 规则

1. 首屏同时出现宁夏意象、产品行动和至少一个原创 IP。
2. Landscape 决定页面气质，Culture 做细节，Character 负责陪伴。
3. 卡片统一圆角、间距和字体，通过渐变、轮廓和内容主题区分页面。
4. 动效只做呼吸、微移、淡入，时长 100–180ms 或 4–8 秒循环。
5. 不下载网络图片作为正式素材；已有合法素材和 CSS 纹理优先。
