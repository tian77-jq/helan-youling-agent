# Authorship Questionnaire

请创作者逐项确认并保存证据：

- 谁画了最早草图？谁确定最终造型？
- 谁制作三视图、源文件和最终导出？
- 是否有共同创作者、外包设计师、同学、老师或委托方？
- 是否使用第三方字体、图片、纹样、模型或参考素材？
- 是否使用 AI 生成初稿、修改、放大或局部素材？工具、日期、条款是什么？
- 学校是否提供经费、设备、课题或委托合同？
- 是否签过团队协议、委托协议或权利归属协议？
- 首次公开时间、渠道、页面和截图证据是什么？
- 三份旧外观设计申请的申请号、通知书、补正期限和官方状态是什么？

未确认项统一填 `UNKNOWN`，不凭项目负责人身份推定全部权利归属。
