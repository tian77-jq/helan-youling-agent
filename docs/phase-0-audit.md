## 修改前真实能力

- 景区与美食联名视觉已完整接入。
- 伴手礼推荐由 `utils/recommend.js` 本地条件规则生成。
- 没有大模型 API、连续对话、Agent、知识检索、图像识别或旅行规划。
- `generateRecommendationByAI` 只是返回规则结果，没有调用 AI。
- 本机埋点包含生成测试数据的方法，不适合作为比赛真实数据。

## 主要问题

### P0

- 首页第一屏仍以 IP 平台展示为中心，用户无法在 3 秒内理解 AI 能完成旅行任务。
- “AI 推荐”实为伴手礼规则匹配，名称与真实能力不一致。
- 无旅行意图解析、结构化行程、连续修改、知识库和安全 AI 后端。

### P1

- 三只萌宠没有差异化 Agent 职责。
- 三语仅静态中英文，阿拉伯语未落地。
- 景区、美食、故事、商城之间缺少任务联动。
- 图片识别与旅行纪念缺失。

### P2

- 存在 “MVP / 路演演示 / 后续接入” 等 Demo 文案。
- 测试数据生成可能污染真实评审数据。
- 技术架构、第三方成果与安全接口说明不完整。

## 风险

- 没有可直接复用的生产 AI 后端，不能把图片识别标记为端到端完成。
- 景区知识来自项目现有内容整理，正式发布前仍需逐条补充官方来源与复核日期。
- 当前机器未检测到微信开发者工具 CLI，命令行无法代替开发者工具编译与真机预览。
