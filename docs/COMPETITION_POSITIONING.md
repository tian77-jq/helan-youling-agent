# 《贺兰有灵》国赛定位

## 项目定位

《贺兰有灵》是 AI 驱动的宁夏文旅数字共创平台，不是旅游信息查询工具。

## 用户体验闭环

发现宁夏 → AI 规划旅程 → 参与文化创作 → 生成数字纪念资产 → 购买/分享 IP 产品。

## 三大核心创新壁垒

1. **AI 灵游 Agent**：识别天数、人数、预算、兴趣、交通和季节，结合宁夏景区、美食、文化知识库，输出带证据的结构化路线。
2. **AI 灵境数字共创空间**：把一次旅行转化为景区 × 文化 × 萌宠的数字纪念卡，形成“旅游消费 → 数字资产”。
3. **三萌宠 IP 生态**：岩羊、骆驼、沙狐分别承载贺兰山生态、丝路文化和荒漠生态，连接对话、生成、故事和文创商品。

## 可信 AI

用户问题 → Agent → Knowledge Grounding Layer → 宁夏知识库 → Evidence → 生成答案。所有事实型推荐标注来源、类型和可信度，创意内容标注 GENERATED，避免把想象当史实。

## 可持续价值

景区合作、IP 授权、数字文创、实体商品和高校推广形成多元商业路径；本地模式保证离线演示，Provider 隔离保证后续接入腾讯混元不影响业务层。
