# 贺兰有灵 · 微信审核测试说明

产品为宁夏 AI 文旅与原创 IP 互动小程序。审核时可从首页进入以下功能：

1. AI 萌宠问答：输入宁夏生态、历史文化或夜游问题，查看对应原创角色的知识增强回答。
2. AI 灵游：输入出行天数、同行人和偏好，生成结构化宁夏行程并继续调整。
3. AI 灵境：选择贺兰山、西夏文化、岩羊与文旅纪念卡，生成 AI 文旅纪念作品；若云端服务暂不可用，页面会明确提示失败，不展示伪造结果。

语音讲解在当前候选版采用字幕降级，不申请录音权限。图片保存仅在用户主动点击保存时申请相册权限。

建议审核路径：

1. 首页 → AI 萌宠，依次输入“宁夏有哪些动物”“宁夏夜游怎么玩”“西夏陵有什么故事”“贺兰山岩画怎么看”。
2. 首页 → AI 灵游，生成 3 天行程，再改为 2 天并添加“贺兰山日落”。
3. 首页 → AI 灵境，选择“贺兰山 + 西夏文化 + 岩羊 + 文旅纪念卡”并生成。生成失败时会显示明确云端失败提示，不会展示伪造成功作品。
4. 打开 IP 故事和商城展示后返回首页，验证页面跳转正常。

本小程序商城为原创文创展示，不提供在线支付、下单或物流服务。AI 生成作品带有 AI/合成内容标识。
