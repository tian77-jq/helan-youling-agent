# 宁夏知识目录 AI 全量回归

## 覆盖范围

- 景点：西夏陵、贺兰山岩画、贺兰山国家森林公园、镇北堡西部影城、水洞沟、沙坡头、沙湖、青铜峡黄河大峡谷、宁夏博物馆、览山公园。
- 美食：手抓羊肉、羊肉臊子面、八宝茶、羊肉老搓面、中卫蒿子面。

## 每个条目的检查

1. 问答命中该条目的知识 ID，并在混元回答中锚定该条目。
2. 一天规划把用户点名的景点或美食作为硬约束保留。
3. 规划卡使用条目自身的本地图片，且图片文件存在。
4. 最终文字不含用户未提及的岩羊、沙狐、骆驼等 IP 幻觉词。
5. 默认行程的时间轴递增，午餐位于中午；普通景点不排进夜间，览山公园默认安排在傍晚。
6. 用户明确要求上午、下午或晚上游览时，该时段优先于默认推荐。

## 最新结果

`scripts/knowledge-catalog-ai-regression.js`：10 个已核验景点、5 个美食、12 个仅视觉展示的概念景点卡，以及 1 条未收录景点边界；共 `55/55` 条问答/规划链路通过。

`scripts/planner-time-sanity-test.js`：10 个默认景点时段、览山上午/下午、西夏陵下午、镇北堡晚上，共 `14/14` 通过。

## 路由规则

- 已知景点、美食：混元基于对应的本地知识事实回答，不允许用其他景点替代。
- 未命中目录的开放问题：混元开放回答；不强迫伪造知识 ID。
- 未收录的具体景点：明确说明目录未收录，不编造景点介绍、路线或图片。
- 页面中的概念景点卡：说明其为联名视觉提案；已核验目录中同名景点优先，不会被概念卡覆盖。
- 规划：混元解析人数、天数、偏好和点名目标；本地规划器只使用目录中存在的景点、美食和图片生成可执行卡片。
