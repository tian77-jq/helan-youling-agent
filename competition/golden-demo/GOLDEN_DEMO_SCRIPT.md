# 180 秒黄金 Demo

## 0–30 秒：痛点

画面：碎片化攻略、单一打卡、文化传播断点。旁白：游客找得到地点，却不一定理解文化，也带不走属于自己的记忆。

## 30–90 秒：AI 灵游

输入“第一次来宁夏，希望三天体验西北文化”。展示画像、Day1/Day2/Day3 路线、景区理由和知识库 Evidence。旁白：不是泛化聊天，而是从宁夏知识资产中规划。

## 90–150 秒：AI 灵境

选择贺兰山、西夏文化、岩羊、旅行纪念卡。展示 Prompt 对象和 LOCAL_MODE 稳定结果。旁白：游客从旅行者变成文化共创者。

## 150–180 秒：商业闭环

展示数字作品 → 岩羊生态明信片/IP 商品 → 景区联名合作。旁白：一次体验沉淀为数字资产，再转化为传播和消费。

演示要求：不依赖网络、不等待模型、不解释代码；每一步只讲用户价值和证据。
