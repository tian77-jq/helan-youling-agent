# 国赛答辩 50 问

每题回答控制在 30 秒，事实不足时明确说明“正在验证”，不夸大。

1. **为什么不用普通 AI？** 我们把宁夏知识、证据链、原创 IP 和消费闭环绑定，输出不是泛化聊天。
2. **为什么选择宁夏？** 西夏、黄河、贺兰山、沙漠、美食和多民族文化构成独特内容组合。
3. **技术壁垒是什么？** 本地知识资产、Grounding、三萌宠 IP、作品沉淀和 Provider 隔离。
4. **如何盈利？** 景区数字服务、IP 授权、文创销售和数字纪念增值。
5. **客户是谁？** 游客、景区、地方品牌、高校和文旅机构。
6. **如何推广？** 景区二维码、高校社群、联名活动和作品分享。
7. **如何复制到其他地区？** 保留 Agent 与数据协议，替换地方知识、文化和 IP 资产。
8. **竞争对手是谁？** 通用地图、旅行平台和泛 AI 工具；我们的差异是文化共创与 IP 转化。
9. **AI 会不会编造？** 事实推荐必须返回 source/type/confidence，未知内容降级或标记创意。
10. **没有网络怎么办？** LOCAL_MODE 使用本地知识和 Demo 数据，核心演示不依赖网络。
11. **混元失败怎么办？** provider 返回统一失败结构，页面展示降级提示。
12. **为什么需要 IP？** IP 让文化内容可记忆、可分享、可授权和可商品化。
13. **三萌宠分别代表什么？** 岩羊代表生态，骆驼代表丝路，沙狐代表荒漠灵性。
14. **数字作品有什么价值？** 把旅行记忆转成可保存、分享和后续授权的数字资产。
15. **作品是否侵权？** 使用自有 IP 与已核验/获授权素材，合作前记录授权范围。
16. **如何保护用户数据？** 先匿名本地存储，真实采集需同意，暂不强制登录。
17. **是否已有景区签约？** 未签约前不宣称合作，当前处于验证和沟通阶段。
18. **用户为什么愿意付费？** 付费点是定制纪念、实体商品和景区服务，而非基础问答。
19. **景区为什么合作？** 获得可信导览入口、作品传播和可量化引流。
20. **高校为什么使用？** 可用于文化实践、创新创业和青年传播。
21. **如何衡量成功？** 任务完成率、作品生成/分享、商品进入率和合作试点结果。
22. **有没有真实用户数据？** 正在按研究计划采集，不用虚构数字替代证据。
23. **如何验证需求？** 大学生、游客、留学生、消费者和景区人员分组测试。
24. **AI 灵游和旅行平台区别？** 它解释宁夏文化并提供证据，而不只给地点列表。
25. **AI 灵境和普通生图区别？** Prompt 由地方文化、景区和原创 IP 共同约束。
26. **Agent 如何协作？** Master 分流，Tour/Culture/Creative/Commerce 子 Agent 处理专门任务。
27. **为什么要多 Agent？** 便于约束事实、隔离故障和替换能力模块。
28. **如何避免系统复杂？** 页面只负责 UI，service 和 provider 隔离，首页保持静态。
29. **如何保证性能？** 首屏无 AI/云函数，深层能力按页面进入，资源和主包持续检查。
30. **如何处理文化敏感性？** 来源、专家复核、授权边界和不确定性标记。
31. **如何处理实时信息？** 没有可靠接口就不输出实时票价、开放或交通断言。
32. **项目能否规模化？** 地方知识协议、IP schema 和 provider 架构可复制。
33. **规模化成本？** 主要是内容核验、合作运营和模型调用成本，可用本地模式控制成本。
34. **商业护城河？** 数据资产、IP 授权、用户作品和景区合作网络会形成复合壁垒。
35. **为什么不是一次性 Demo？** 有服务层、运营预留、指标设计和验证路线。
36. **目前最大风险？** 真机验收、内容权威复核和首批合作，需要通过试点解决。
37. **如何解决最大风险？** 分阶段真机、专家、用户和景区验证，不提前承诺结果。
38. **如何做内容更新？** operation 目录预留景区/IP/作品管理结构。
39. **如何做商品管理？** product schema 区分实体商品、数字作品和联名状态。
40. **如何形成传播？** 作品分享卡、景区入口和好友查看形成自然传播链。
41. **如何防止低俗或错误生图？** Prompt 安全过滤、审核状态和 provider 失败降级。
42. **是否依赖某个模型？** 不依赖，模型藏在 provider，LOCAL/HUNYUAN 可切换。
43. **为什么是新文科？** 技术服务文化理解、文旅场景和社会传播，不是纯技术展示。
44. **社会价值是什么？** 让地方文化被年轻人理解、参与和传播。
45. **团队如何分工？** 技术、产品、IP、市场四个责任域协同。
46. **如何证明团队能做？** 用可运行工程、数据结构、Demo、测试报告和验证计划证明。
47. **十万元奖金怎么用？** 优先内容权威核验、用户测试、景区试点和 IP 样品，不写成已获得收入。
48. **未来三个月做什么？** 真机稳定、真实调研、专家复核、首个景区沟通和混元小流量测试。
49. **五年愿景？** 成为可复制的地方文旅数字共创基础设施。
50. **一句话总结？** 让游客不只游宁夏，还能创造、分享并带走属于自己的宁夏文化记忆。
