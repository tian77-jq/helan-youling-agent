# Scenic AI Engine Core

`core` contains region/scenic-neutral contracts. It must not import `宁夏`、`沙坡头`、`银川` or other buyer-specific strings. Scenic truth, themes, characters, policies and templates belong in `adapters/<scenicId>`.

The current extraction is interface-ready, not a second runtime. Existing mini-program behavior remains the Ningxia adapter while the contracts below define the commercial boundary.

## Lifecycle

`DISCOVER → PLAN → ARRIVE → EXPLORE → UNDERSTAND → EXPERIENCE → CREATE → SHARE → RETURN`

## Capability flags

See `capability-flags.js`. A buyer can deploy `AI_TRIP` or `STORY + MEMORY` without taking every module.
